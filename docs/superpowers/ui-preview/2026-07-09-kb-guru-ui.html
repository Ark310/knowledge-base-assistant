When we draw down in full from a forward deal that has more than one transaction line, the margin is taken from the GBP cost for each line — duplicating the margin used. How do we avoid this going forward? (TD Client Server)
dsKB Guru· Local · 2.1s

Drawdown margin duplication is a known TD Client Server issue: on a full drawdown of a multi‑line forward deal, margin is calculated once per transaction line instead of once for the drawdown event. Ticket #54000

Root cause

The drawdown routine loops the transaction lines and applies the GBP‑cost margin on each pass, so an n‑line contract books n× the intended margin. The client expects a single margin calc for the full drawdown. Ticket #54000

Resolution

  1. Aggregate the lines before the margin step so margin is computed once against the total drawn amount, not per line. Ticket #54000
  2. For partial drawdowns, recalc margin on the outstanding balance after each draw (a related but distinct case). Ticket #45615
  3. Verify against the margin‑detail module: the margin deal created should match the initial margin required. Ticket #45615
